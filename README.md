# 📀🎞️ DVD Rental - system wypożyczalni płyt DVD

    Terminalowa aplikacja napisana w C++ symulująca działanie wypożyczalni płyt DVD - bardzo popularne miejsce początku lat 2000.  

## O projekcie

Projekt powstał w ramach przedmiotu "Języki Programowania Obiektowego" w celu nauki zaawansowanych struktur obiektowego C++ oraz architektury aplikacji.

## Główne funkcjonalności

* **Panel administratora**
    * baza filmów i klientów
    * dodaj/usuń/edytuj film

* **Panel klienta**
    * katalog dostępnych filmów
    * moje wypożyczenia
    * zwróć film

* **System wypożyczeń**
    * „automatyczne” liczenie dni
    * naliczanie kar za opóźnienia w oddaniu
      
* **Wyszukiwanie filmów**
    * różne kryteria (tytuł, gatunek, aktor)

* **Rejestracja nowych klientów**

## Struktura Projektu
- `src/` - pliki źródłowe (.cpp)
- `include/` - pliki nagłówkowe (.h)  
- `data/` - pliki tekstowe (.txt)
- `docs/` - dokumentacja projektu (PDF)
